# Canvas Arcade Hub

A collection of three browser-based HTML5 Canvas mini-games with neon visuals and Web Audio API sound effects.

## Play locally

Open `index.html` in a modern browser, or serve this folder with a static web server.

## Games and controls

- **Neon Chaser:** Arrow keys or `WASD` to evade enemies.
- **Neon Snake:** Arrow keys or `WASD` to move.
- **Neon Flappy Bird:** `Space`, `↑`, `W`, or click/tap the canvas to flap.

## Deployment

Pushing to `main` triggers the GitHub Actions workflow in `.github/workflows/deploy-pages.yml`, which publishes the site to GitHub Pages.
